# すらいむ たしたし

4さいごろの こどもが、ぷにょぷにょの すらいむと スネアドラムの リズムで たしざんを おぼえる ゲームです。

## あそびかた

1. タイトルで **「あそぶ！」**（または だんの ボタン）→ **「▶ スタート」**
2. **「1」「たす」「1」「は？」** が リズムよく じゅんばんに でてくる
   - かずの ぶんだけ スネアドラムが「た」と なって、すらいむが 1ぴきずつ ぽよんと でてくる
   - 1 は「た」、2 は「たった」、3 は「たったった」…
   - 「たす」は「たた」、「は？」は「た」
   - れい: 1 たす 1 は？ →「た」「たた」「た」「た」／ 2 たす 1 は？ →「たった」「たた」「た」「た」
3. したに こたえが **3たく** で でるので、ただしい かずを タップ
   - **せいかい**: こたえの かずだけ「たったった…」と なりながら、すらいむが 1ぴきずつ くっついて、かずに おうじて おおきく なって 1つに がったい
   - **まちがい**: 「ブブー」と なって、こたえの ならびが かわるだけ（しっぱいは つまらなく）
   - 「🔁 もういちど きく」で もんだいを もういちど きける
4. **1の だん** は 1+1 〜 1+10。10もん ぜんぶ できたら クリア（2の だんは 2+1 〜 2+10 … 10の だんまで）

### 🗡 ぶき
だんを クリアするたびに ぶきが もらえて、すらいむが もって でてきます。だんだん ごうかに なります。

| だん | ぶき |
| --- | --- |
| 1 | ぼう |
| 2 | きの けん |
| 3 | ハンマー |
| 4 | トゲトゲ こんぼう |
| 5 | ぎんの けん |
| 6 | おおきな おの |
| 7 | こおりの やり |
| 8 | ほのおの けん |
| 9 | かみなりの ハンマー |
| 10 | にじいろの けん |

タイトルの **「🗡 ぶき」** で、もっている ぶきから すきな ものを えらべます（「なし」も できます）。

### 👑 ボス
**3・6・10の だん** の さいごに ボスが でてきます。すらいむは もっている ぶきを ふりまわして たたかいます。

- がめんに でる **せん（わく）** を「ここ」から ⭐ まで ゆびで なぞると、ボスに ダメージ
- なぞるたびに スネアが「た、た、た」と なります。はみだしたら しずかに さいしょから
- 3の だん **ゴロゴロン**: 2かい ／ 6の だん **ドラゴラン**: 3かい ／ 10の だん **まおうスライム**: 5かい なぞったら クリア

### ほぞん
- クリアした だん・ぶきは ブラウザ（localStorage）に ほぞんされます
- タイトルの **「⚙️ おとなよう」**（たしざんの こたえを いれて ひらく）で
  - だんを えらんで、その だんから あそべるように する（まえの だんは クリア・ぶきも もらえる）
  - 「かずを こえで よむ」の オン／オフ
  - 「さいしょから（ぜんぶ けす）」

## こえ
こえは つぎの じゅんに さがして ならします。マナーモードは はずしてください。

1. **じぶんたちで とった こえ**（🎙 こえの スタジオ）
2. **VOICEVOX で つくった こえ**（`audio/voice/*.mp3`。まだ はいっていません ↓）
3. **ブラウザの よみあげ**（Android は せってい → システム → 言語と入力 → テキスト読み上げ で「Google 音声サービス」の 日本語）

### 🎙 じぶんたちの こえに する（こえの スタジオ）
「ひらがなまてまて」と おなじ しくみです。タイトルの **「🎙 こえ」** から、ゲームの ぜんぶの セリフ（かず「いち」〜「にじゅう」・たす・は？・ほめことば・すらいむ・ボス）を じぶんたちの こえに とりかえられます。

- **●** で ろくおん → よみおわったら **■**。まえと うしろの しずかな ところは じどうで けずり、おおきさも そろえます
- **▶** で きく、**↺** で もとの こえに もどす
- **📨 えらんだ セリフを LINEで たのむ** → ともだちは リンクを ひらいて ろくおんし、**「✅ できた！ おくりかえす」** で こえパック（PDF）を おくりかえす
- とどいた PDF を ほぞんして **「📥 こえを よみこむ」** で いれる
- **「📤 とった こえを おくる」** で べつの スマホへの おひっこしや バックアップにも

### VOICEVOX の こえを つくる（パソコン・Linux）
セリフは `js/data.js` の `LINES` に まとめてあります。かえたら つくりなおします。

```sh
node tools/voices/lines.mjs                          # セリフを あつめる → tools/voices/lines.json
VV_DIR=/path/to/voicevox python tools/voices/gen.py  # ない ぶんだけ つくる → audio/voice/
```

`VV_DIR` には VOICEVOX CORE（0.16）の `voicevox_onnxruntime-linux-x64-1.17.3/`・`open_jtalk_dic_utf_8-1.11/`・`vvms/0.vvm`・`vvms/4.vvm` を おきます。python に `voicevox_core` の whl、それと ffmpeg も つかいます。

| やく | こえ |
| --- | --- |
| ナレーション（かず・たす・は？・ほめことば） | VOICEVOX:春日部つむぎ |
| すらいむ | VOICEVOX:ずんだもん |
| ボス | VOICEVOX:玄野武宏 |

## ☁️ データを ほかの スマホと きょうゆう する
「ひらがなまてまて」と おなじ しくみ・おなじ Firebase プロジェクトを つかいます（データは `accounts/slime-{ID}` に わかれて いるので まざりません）。

タイトルの **「☁️ きょうゆう」** で ID を いれると、すすみぐあい・ぶき・とった こえ が ウェブに ほぞんされます。ほかの スマホで おなじ ID を いれると、おなじ データで あそべます。

- はじめての スマホ: 「ID を つくる」→「つなぐ」（ID は メモして おく）／ ほかの スマホ: その ID を いれて「つなぐ」
- あそぶ・ろくおんする・アプリを ひらく たびに じどうで どうき
- **「いま どうきする」** で 🔀 まぜる（おすすめ）／ ⬇️ うけいれる ／ ⬆️ こうしんする を えらべます
- ⚠️ ID を しっている ひとは だれでも データを みたり かえたり できます。かぞく だけの ひみつに してください

Firebase の せってい（`js/cloud-config.js`）と ルール（`firestore.rules`）は「ひらがなまてまて」と おなじです。べつの プロジェクトに する ときは「ひらがなまてまて」の README の てじゅんで つくって `js/cloud-config.js` を かきかえてください。
